This repository includes three files:
1. Alignment_to_windowed_depth.sh which generate the windowed read depth for indiviual short-read alignments using bedtools.
2. Hypanus_mapq60_female-to-male_ratio.R which calculate and plot the female-to-male ratio of the Atlantic stingray.
3. Carcharodon_mapq60_female-to-male_ratio.R which calculate and plot the female-to-male ratio of the white shark.
